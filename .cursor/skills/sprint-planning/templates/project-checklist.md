# Project Checklist

## Sprint 0 — Foundation

### Environment
- [ ] Repository created and cloned
- [ ] Development environment set up (Python venv / Node / etc.)
- [ ] Dependencies installed and lockfile committed
- [ ] `.gitignore` configured (data files, secrets, build artifacts)
- [ ] README with setup instructions

### Structure
- [ ] Project structure created (see `/project-scaffolding` skill)
- [ ] Configuration management set up (env vars, YAML configs)
- [ ] Logging configured

### Development Workflow
- [ ] Linter/formatter configured and passing (Ruff, ESLint, etc.)
- [ ] Test framework set up with one passing test
- [ ] CI pipeline running (lint + test on push)
- [ ] Branch strategy defined (main + feature branches)

### First Vertical Slice
- [ ] One end-to-end user journey working
- [ ] Deployed to staging/preview (if applicable)
- [ ] Can be demonstrated to stakeholders

## Ongoing Sprint Checklist

### Planning
- [ ] Sprint goal defined (one sentence)
- [ ] 3-7 items committed with definitions of done
- [ ] Blockers and dependencies identified
- [ ] Effort estimates assigned (S/M/L)

### Execution
- [ ] Daily async standup (did/will do/blockers)
- [ ] Docs updated when process changes
- [ ] Tests written for new functionality

### Review & Retro
- [ ] Sprint goal achieved? (yes/partial/no)
- [ ] Incomplete items returned to backlog with notes
- [ ] One retro action item for next sprint
